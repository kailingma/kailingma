I'm Kai, a teenager who enjoys being outside, coding, and building hardware. My favourite kind of code is the kind that survives rain.

I am a member of [@hackclub](https://hackclub.com), and you should be too!

Some things I've built or am building:

- **Rainshell** - a weatherproof server rack for the outdoors, so my servers get to spend as much time outside as I do
- **Supermicro PSU fan swap** - two Noctua fans on a 3D-printed adapter, silencing a screaming 1U power supply. Lots of cable surgery was required
- **CanSat ESP32-CAM** - firmware for a camera in a can, taking pictures on the way down from near-space
- **Flux-Clock** - an Arduino alarm clock. Automatic dimming: TODO. Physical buttons: TODO
- **silverbulletmd-docx-viewer** - a plugin so I never have to leave markdown just because someone sent me a Word file
